\subsection*{Marginal Stability \& Resonance}

\paragraph{4)} Consider a continuous-time LTI system with system function:
$$H(s) = \frac{s + 1}{s^2 + 2\alpha s + 16}$$
where $\alpha$ is a real parameter.

\subparagraph{a)} Find the range of $\alpha$ for which the system is (i) asymptotically stable, (ii) unstable, and (iii) marginally stable.

\textbf{Solution:} The poles of the system are the roots of the characteristic equation $s^2 + 2\alpha s + 16 = 0$. Using the quadratic formula, the poles are:
$$s = -\alpha \pm \sqrt{\alpha^2 - 16}$$
\begin{itemize}
    \item \textbf{(i) Asymptotically stable:} Requires all poles to have strictly negative real parts ($\text{Re}\{s\} < 0$). Thus, $-\alpha > 0 \implies \alpha > 0$.
    \item \textbf{(ii) Unstable:} Requires at least one pole with a positive real part ($\text{Re}\{s\} > 0$). Thus, $\alpha < 0$.
    \item \textbf{(iii) Marginally stable:} Requires poles to lie purely on the imaginary axis with multiplicity one. This occurs when $\alpha = 0$, giving poles at $s = \pm j4$.
\end{itemize}

\subparagraph{b)} For the value of $\alpha$ that results in marginal stability, find the impulse response $h(t)$ for $t \geq 0$.

\textbf{Solution:} When $\alpha = 0$, the system function is:
$$H(s) = \frac{s + 1}{s^2 + 16} = \frac{s}{s^2 + 4^2} + \frac{1}{4}\left(\frac{4}{s^2 + 4^2}\right)$$
Taking the inverse Laplace transform for $t \geq 0$:
$$h(t) = \left( \cos(4t) + \frac{1}{4}\sin(4t) \right) u(t)$$

\subparagraph{c)} For the marginally stable system, determine the zero-state response $y(t)$ when the input is $x(t) = \cos(4t)u(t)$. Explain how this response demonstrates resonance.

\textbf{Solution:} With $x(t) = \cos(4t)u(t)$, the input frequency $\omega = 4$ matches the natural resonant frequency of the system ($\omega_0 = 4$). The zero-state response in the $s$-domain is:
$$Y(s) = H(s)X(s) = \left(\frac{s + 1}{s^2 + 16}\right)\left(\frac{s}{s^2 + 16}\right) = \frac{s^2 + s}{(s^2 + 16)^2}$$
Using inverse Laplace transform pairs for repeated imaginary poles:
$$y(t) = \left[ \frac{1}{2}t\cos(4t) + \frac{1}{8}\sin(4t) + \frac{1}{8}t\sin(4t) \right] u(t)$$
Because of the terms multiplied by time $t$ ($t\cos(4t)$ and $t\sin(4t)$), the response grows linearly without bound as $t \to \infty$. This unbounded growth when the input frequency matches the natural system frequency is the hallmark of resonance.
