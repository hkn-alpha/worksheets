# LaTeX Basics
For guidance on the basics of LaTeX, refer to [Overleaf -- Learn LaTeX in 30 minutes](https://www.overleaf.com/learn/latex/Learn_LaTeX_in_30_minutes) or the [guide document](latex_ref_guide.pdf) in this respository.

## Editing and Compiling LaTeX Files

We recommend that you use Overleaf to edit and create worksheets, as all engineering students receive Overleaf Premium for free. Additionally, Overleaf allows for multiple people to easily collaborate on the same worksheet. Details on how to set up Overleaf and edit/update worksheets can be found in the [Worksheet LaTeX Guide](Worksheet_LaTeX_Guide.pdf). 

If you prefer to edit and compile LaTeX files locally, first find the appropriate LaTeX distribution for your OS on [The LaTeX Project](https://www.latex-project.org/get/). After cloning this repository, you can open up `.tex` files in the corresponding editor to make edits and compile PDFs when you make updates.

TeXStudio is the recommended distribution for Linux. TeXLive and MacTeX are the reccomended distributions for Windows and MacOS respectively.
